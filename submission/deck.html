The Problem
India's PHC Supply Chain is Broken
💊
Medicine Stock-Outs
Life-saving drugs — insulin, ORS, antimalarials — run out during seasonal surges while nearby PHCs hold expiring surplus.
📋
Paper-Based Inventory
Rural PHCs still rely on handwritten stock registers. Manual reporting creates days of lag before critical shortages surface.
🔍
Delayed Detection
No real-time cross-facility visibility. By the time a stock-out is reported, patients are already denied medicines.
🚚
No Peer Redistribution
No mechanism to identify surplus at adjacent facilities and coordinate emergency transfers without waiting for central directives.
India has ~30,000 Primary Health Centres serving over 900 million rural citizens — all without real-time supply intelligence.

How It Works
End-to-End Operational Flow
1
PHC Stock Data Ingested
72 simulated PHCs across Maharashtra, Uttar Pradesh, Tamil Nadu with synthetic daily consumption data. Architecture supports CSV upload and paper register OCR for future real-data onboarding.
2
14-Day Demand Forecast
Per-facility Ridge regression model calculates daily consumption trend. Forecasts days-of-stock remaining per medicine. Recharts visualization displayed per PHC.
3
Stock-Out Alerts Ranked
Critical (<3 days) and Deficit (<7 days) alerts surfaced in ranked queue. Severity badges, daily consumption rate, and stock runway shown per facility.
4
Gemini AI Explains the Alert
One click calls Gemini Flash with grounded telemetry context. Returns: root cause, stock runway analysis, and recommended intervention. Explicitly labeled "Powered by Google Gemini".
5
AI Redistribution Recommended
Greedy Haversine proximity algorithm identifies surplus PHC nearest to deficit PHC. Intra-state transfers prioritized; inter-state orchestrated when necessary. Transfer cards shown in Transfers tab.
6
Transfer Applied, Dashboard Updates
Single or batch apply triggers REST API call. MySQL stock records updated. Map transfer polylines animate. KPI "Stock-outs Prevented" counter increments live.

Data Transparency
What Is Real vs Demo Data
✓ Real-World Context
✓
Geographic data: Actual Indian state and district names — Maharashtra (Nagpur, Pune), Uttar Pradesh (Lucknow, Kanpur, Varanasi), Tamil Nadu (Chennai, Coimbatore, Madurai).
✓
Medicine list: Clinically valid medicines — Paracetamol, Amoxicillin, ORS, Insulin, Artemisinin ACT, Iron-Folic Acid, Metformin, Cotrimoxazole, Measles Vaccine.
✓
Problem framing: Based on documented challenges at India's PHC network (~30,000 facilities nationally).
✓
Algorithm logic: Haversine geodesic distance, FedAvg aggregation protocol, Ridge regression forecasting — all standard, validated approaches.
✓
AI responses: Strictly grounded in live telemetry provided to Gemini; zero hallucinated patient data.
⚗️ Synthetic Demo Data
⚠
PHC stock levels: Synthetically generated using seed-42 reproducible data. Not sourced from real government or HMIS systems.
⚠
Consumption figures: Simulated daily consumption rates. Not actual patient dispensing records from any PHC.
⚠
PHC locations: Representative lat/lng coordinates within correct districts, not verified GPS positions.
⚠
Federated learning: Simulated FedAvg with synthetic state-node separation. Not a live distributed training deployment.
⚠
User uploaded images: Test register images supplied for OCR demo; architecture supports real uploaded images.
🏗️ Real-Data Path (Architecture-Ready)
The backend DataStore, JPA entity layer, and CSV import modal are designed to ingest real PHC data from e-Aushadhi, HMIS CSV exports, or direct API feeds — with zero architectural changes required.

Roadmap to Production
All items below are clearly labeled as future scope — not present in the current prototype
Data & Integration
🏛️
Real Government PHC Data: Integration with e-Aushadhi, HMIS, and NHM data pipelines. Direct API feeds from state health department systems replacing synthetic demo data.
📡
Live Data Feeds: Real-time stock consumption pushed from point-of-care dispensing systems — eliminating manual register entry and CSV upload dependency.
🏥
Broader Health Resource Monitoring: Extend beyond medicines — beds, oxygen, vaccines, diagnostic equipment, and human resources across facilities.
Platform & Scale
🔐
Production-Grade Auth & Security: OAuth2 / SSO integration with NIC login. Role-based access control enforced at API layer. Audit logging for all stock mutations.
🌐
Real Distributed Federated Learning: Current prototype simulates FedAvg in a single JVM. Production would run actual state-separated compute nodes with encrypted weight transmission.
📱
Mobile-First Field App: Progressive web app or native Android app for PHC pharmacists to submit daily stock counts, receive alerts, and request emergency resupply — even with intermittent connectivity.
☁️
National Scale Deployment: Cloud-native architecture designed for 30,000 PHCs across all 28 states. Performance benchmark prototype demonstrated <6s for 5,000-facility redistribution on single machine.
